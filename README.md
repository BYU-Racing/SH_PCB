### Description
STM32-powered data collector with hookups for analog and digital sensor signals and CAN connections. Interfacing with MCU is possible by USB or STLINK. Also includes headers for stacking a BMI IMU breakout board, an on-board thermistor, and a 12V SOC circuit.
